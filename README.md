# online_banking_system
A Python-based project that simulates real-world banking operations like user registration, login, deposit, withdrawal, balance check, and fund transfer. Built using Python and SQLite, it ensures secure transactions and efficient database management.
Key Features:
Secure user authentication
Deposit, withdrawal, and fund transfer
Transaction history tracking
SQLite database integration
Tech Stack: Python | SQLite 
A practical project demonstrating Python programming, database handling, and secure coding skills.
